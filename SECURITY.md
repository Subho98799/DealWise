# Security

## Reporting a vulnerability

Please report suspected vulnerabilities privately using the contact address defined by [`CONTACT_EMAIL`](frontend/src/config/app.ts). It is currently a placeholder (`support@example.com`) and must be replaced with a monitored mailbox before public launch.

Include the affected version or commit, the security impact, and concise reproduction steps that use only a local or test environment. Do not include real user data, credentials, cookies, tokens, or production connection strings.

Please do not publish an unpatched issue or test against production, Google, Neon, Render, or Vercel systems. This project has no published bug-bounty program or guaranteed response-time commitment.
