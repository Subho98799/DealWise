# Platform logos

Real platform images are bundled as `png`, `jpg`, `jpeg`, `webp`, or `svg`.

- Name each file after the platform: lowercase letters and digits only, plus the extension.
- Examples: `amazon.jpg`, `flipkart.png`, `myntra.jpg`, `meesho.jpg`, `ajio.jpg`, `nykaa.svg`, `blinkit.png`, `zepto.png`.
- Any other platform works too: "My Shop" becomes `myshop.png`.
- No code change is needed. The app imports every image here automatically and prefers raster files over SVG for the same name.
- Raster logos are shown in full colour; SVG marks should use `currentColor` so the platform tint applies.
- Do not commit third-party trademarked artwork unless you have permission to use it.
