# Platform logos

Bundled monochrome marks are tinted with the platform colour tokens.

- Name each file after the platform: lowercase letters and digits only, plus `.svg`.
- Examples: `amazon.svg`, `flipkart.svg`, `myntra.svg`, `meesho.svg`, `ajio.svg`, `nykaa.svg`, `blinkit.svg`, `zepto.svg`.
- Any other platform works too: "My Shop" becomes `myshop.svg`.
- No code change is needed. The app imports every `.svg` here automatically.
- Use `currentColor` for fills and strokes so the theme tint applies.
- Do not commit third-party trademarked artwork unless you have permission to use it.
